## 맡은 것

중고의류 판매 서비스 '핏핏'에서 백엔드와 AI 기능을 전담했습니다. 상품 등록·거래·판매자-구매자 채팅 기능을 구현하고, 가상 피팅 API를 연동했습니다.

## 구현

Spring Data JPA와 QueryDSL로 도메인 모델링을 했습니다. 상품·거래·채팅이 서로 얽힌 도메인이라 초기 설계 단계에서 엔티티 관계를 명확히 잡는 데 신경을 썼습니다. 배포는 GitHub Actions 기반으로 AWS EC2에 올라가는 CI/CD 파이프라인을 직접 구성했습니다.

## 결과

탄소중립 INNOVATION ACADEMY에서 최우수상을 받았습니다. 중고거래라는 도메인 자체가 재사용을 통한 탄소 절감이라는 취지와 맞았고, 여기에 가상 피팅으로 구매 전 확인 경험을 더한 게 좋은 평가를 받은 지점이었습니다.
