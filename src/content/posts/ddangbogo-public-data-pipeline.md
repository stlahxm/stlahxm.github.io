## 맡은 것

공공데이터 활용 창업경진대회 출품작 '땅보고'에서 서비스 개발을 전담하고 있습니다. 국토교통부, 한국농어촌공사 등 다종의 공공데이터 오픈 API를 연동해 농지 위험 요인을 수집하는 파이프라인을 구축했습니다.

## 문제 인식과 해결: 외부 API 장애 격리

여러 공공기관의 API를 동시에 쓰다 보니, 그중 하나만 장애가 나도 전체 분석 결과가 막히는 게 문제였습니다. 외부 API 실패 시 예외를 그대로 전파하지 않고 일관된 폴백값을 반환하도록 설계했고, 일시적 오류는 지수 백오프로 재시도하도록 해 일부 데이터 소스 장애가 전체 분석 결과를 막지 않도록 방어했습니다.

## 문제 인식과 해결: 순차 호출 병목

6개 분석 항목을 순차로 호출하는 구조라 응답이 느렸습니다. 150 VUs 부하 테스트로 병목 지점을 확인한 뒤, 스레드풀 기반 병렬화로 전환했습니다.

## 최종 성과

p95 응답 시간이 32.8% 단축됐고, 처리량은 1.6배 늘었습니다. 외부 API 여러 개에 의존하는 구조에서 장애 격리와 병렬화를 함께 적용한 결과입니다.
